# Frontend Portal & Admin Dashboard - Gym/Yoga AI & RBAC

Được thiết kế và xây dựng bởi: **Nguyễn Chí Nhân (Frontend UI/UX Lead)**

## Công nghệ sử dụng
- **Core:** React 18, Vite
- **Styling:** Tailwind CSS, Heroicons / Lucide React
- **Routing:** React Router v6 (Hỗ trợ Protected Routes theo RBAC)
- **HTTP Client:** Axios với Interceptor tự động gắn Bearer Token & Refresh Token

## Các tính năng chính
1. **Xác thực:** Đăng ký, Đăng nhập, Profile thể trạng, tính chỉ số BMI.
2. **Thư viện bài tập:** Catalog bài tập Gym/Yoga, bộ lọc nhóm cơ/độ khó, chấm sao đánh giá.
3. **AI Wizard:** Biểu mẫu đa bước khảo sát nhu cầu & hiển thị lộ trình tập luyện tuần cá nhân hóa.
4. **Admin Dashboard:** Ma trận phân quyền RBAC Matrix trực quan, quản trị danh sách người dùng.
