# WBS 2.17 & 2.18 / SCRUM-78, SCRUM-79: Exercise Catalog Search & Filtering Specs
- **Actors:** Member, Trainer (PT), Guest
- **Functionality:**
  - Search exercises by name, equipment, or primary muscle group.
  - Multi-select filters for category: Gym (Hypertrophy/Strength) vs. Yoga (Vinyasa/Hatha/Asana).
  - Difficulty filter: Beginner, Intermediate, Advanced.
- **Acceptance Criteria (AC):**
  - Search results return in < 300ms.
  - Pagination displays 12 exercise cards per page.
  - Filter state synchronized with URL query parameters.
