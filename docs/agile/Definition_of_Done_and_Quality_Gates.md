# WBS 1.16 / SCRUM-16: Definition of Done (DoD) & Definition of Ready (DoR)
## 1. Definition of Ready (DoR)
- User story has clear business description and acceptance criteria (AC).
- UI mockup / Figma spec attached (for FE tasks).
- API endpoint contract defined (for BE tasks).
- Story points estimated during Sprint Planning.

## 2. Definition of Done (DoD)
- Code follows PEP8 (Backend) and ESLint/Prettier (Frontend).
- All unit tests and QA integration tests pass 100%.
- Pull Request reviewed and approved by Tech Lead / PM.
- Deployed and verified on staging/preview environment.
